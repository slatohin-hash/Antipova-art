Вход

Для входа нужен ключ доступа GitHub. Его создают один раз, и он хранится только на этом устройстве.

Как получить ключ
  1. Владелец сайта (аккаунт slatohin-hash) открывает github.com/settings/personal-access-tokens/new.
  2. Token name: «Админка сайта». Expiration: выберите самый долгий срок (например, 1 год).
  3. Repository access → Only select repositories → выберите Antipova-art.
  4. Permissions → Repository permissions → Contents → Read and write. Остальное не трогайте.
  5. Нажмите Generate token и скопируйте ключ: он начинается с github_pat_.

Порядок здесь такой же, как в галерее на сайте. Нажмите на картину, чтобы изменить подписи.
